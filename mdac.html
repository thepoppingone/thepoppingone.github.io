Fill this in once per traveller. It produces a profile for an iPhone Shortcut (Safari) and a bookmarklet (Chrome). Both run mdac-fill.js on the MDAC registration page. You still solve the slider puzzle and tap Submit yourself.

Privacy: this page saves nothing and sends nothing. Your details stay in this tab until you copy them into your own Shortcut or bookmark. The hosted script contains no personal data. It only fills in the MDAC form that's open on your phone.

iPhone Safari: Shortcut

One-time setup (about 5 minutes)

  1. Open Shortcuts, tap +, name it Fill MDAC.
  2. Tap the (i) / settings icon and turn on Show in Share Sheet. Set its input types to Safari web pages only.
  3. Add a Text action and paste the profile above. If several people travel together, add Choose from Menu first with one option per person, each holding its own Text action.
  4. Add Ask for Input: type Date, prompt Arrival date. Then add Format Date: Custom format dd/MM/yyyy. Then add Set Variable Arrival.
  5. Repeat the previous step for Departure.
  6. Add Get Contents of URL with .
  7. Add Run JavaScript on Web Page with input Shortcut Input. Replace its code with the four lines below, inserting each variable from the variable bar where it's in [brackets]: 
    var MDAC = [Text];
MDAC.arrDt = "[Arrival]";
MDAC.depDt = "[Departure]";
[Contents of URL]
  8. Optional: add Show Result to see which fields were filled.

To use it: open the MDAC page in Safari, tap Share, then Fill MDAC. The first time, allow the Shortcut to access the site. Check the form, solve the slider, and tap Submit.

If [Contents of URL] doesn't insert as code, add a Get Text from Input action after Get Contents of URL and use its output instead.

Sharing the Shortcut

Before sharing, delete the Text action with your profile, or turn it into an Import Question (in the Shortcut's settings). Then use Share → Copy iCloud Link. The other person adds the Shortcut, generates their own profile on this page, and pastes it in. Their details never pass through you.

Chrome (or any browser): Bookmarklet

  1. Bookmark any page and name it something like MDAC Me.
  2. Edit that bookmark and replace its URL with the copied bookmarklet.
  3. On the MDAC page: on desktop, click the bookmark. In iOS Chrome, type MDAC Me in the address bar and tap the bookmark in the suggestions. It asks for your arrival and departure dates, then fills the form.

The bookmarklet stores your details in your bookmarks. If Chrome sync is on, that includes your Google account.
